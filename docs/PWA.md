# Installable app (PWA)

Home Control can be added to the home screen and opens full screen like an app.

## Install

- **iPhone (Safari):** open the app, tap **Share** > **Adicionar à Tela de Início**. iOS uses the 180 px
  `apple-touch-icon` and the `apple-mobile-web-app-*` tags (title "Home Control", translucent status bar).
- **Android (Chrome):** menu > **Instalar app** / **Adicionar à tela inicial**.
- **Desktop (Chrome/Edge):** the install icon in the address bar.

## What is provided

- `/manifest.webmanifest` (name, `standalone` display, theme colors, `pt-BR`), generated by
  `apps/web/src/app/manifest.ts`.
- Icons are generated by the app (no image files to maintain): `/icon`, `/apple-icon` and
  `/pwa-icon/{192,512,maskable}`; the maskable one keeps extra margin so Android can crop it. All of them
  and the manifest are reachable without logging in, as installers require.
- **Safe areas:** header, bottom navigation, dialogs and the login screen pad for the iPhone notch and
  home indicator (`env(safe-area-inset-*)`).
- **Touch:** navigation targets are at least 56 px tall and controls 44 px; the bottom bar shows all five
  sections (Início, Dispositivos, Cenas, Música, Ajustes).
- **Offline indicator:** when the browser reports no network, a banner says _Sem conexão_, that no command
  will be sent and that what is shown may be out of date.

## Deliberate limitations (read this)

- **There is no offline mode.** No service worker, no cache and no command queue. The app only controls
  devices while it can reach the Home Control server on the home network; it never pretends otherwise.
  Launching the installed app with no network shows the browser's own "no connection" page.
- The offline banner relies on the browser's online/offline signal. If the Wi-Fi is up but the server or
  Home Assistant is down, the existing per-screen messages and the status indicator explain it instead.
- iOS only treats https (or localhost) pages as fully installable apps with some features; on plain `http`
  over the LAN, "Adicionar à Tela de Início" still works but behaves as a bookmark with full-screen mode.
- Not verified on a physical iPhone or Android device in this task (see the pull request).
